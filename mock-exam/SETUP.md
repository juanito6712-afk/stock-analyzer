# 模擬試題網頁版 — 一次性安裝（約 10 分鐘）

裝好之後：**出題在雲端的 Claude Code，考卷存在你的 Google Drive，作答連結任何人點了就能做，成績自動回寫到 Drive 的試算表。**
你的電腦全程不用開。

---

## 你要做的事（只做一次）

### 1. 建立 Apps Script 專案

1. 到 <https://script.google.com/home>，按「新增專案」。
2. 左上角專案名稱改成 `模擬試題`。

### 2. 貼上程式碼

1. 把 `Code.gs` 的全部內容，貼進編輯器裡預設的 `Code.gs`（原本的 `myFunction` 整個刪掉）。
2. 左邊「檔案」旁邊按 `+` → 「HTML」→ 檔名打 **`index`**（一定要叫 index，不要加 .html）→ 把 `index.html` 的全部內容貼進去，覆蓋原本的範本。
3. 存檔（Ctrl+S）。

### 3. 第一次授權

1. 上方函式下拉選單選 **`setup`**，按「執行」。
2. 會跳出授權視窗 → 選你的 Google 帳號 → 出現「Google 尚未驗證這個應用程式」是正常的（因為是你自己寫的），按 **「進階」→「前往『模擬試題』(不安全)」→ 允許**。
3. 下方「執行紀錄」會印出資料夾 ID、成績表 ID。看到就代表成功了。

這一步會在 `模擬試題/` 裡建立兩個東西：

- `名單.json`：誰可以作答
- `作答紀錄`（Google 試算表）：成績會寫在這裡

### 4. 改名單

去 Drive 打開 `模擬試題/名單.json`，把代碼換成你要的（隨便英數字都可以，像 `yx-2026`）：

```json
{
  "open": false,
  "students": [
    { "code": "yx-2026", "name": "宇翔", "grade": "8", "group": "家裡" },
    { "code": "ya-2026", "name": "宇安", "grade": "9", "group": "家裡" },
    { "code": "chen-01", "name": "陳同學", "grade": "8", "group": "家教A" }
  ]
}
```

- `code`：作答代碼，一人一組。要停掉某個人，加 `"disabled": true` 就好。
- `group`：分組，出題時可以指定「這份只給家教A」。
- `open`：設成 `true` 的話，沒有代碼也能作答（會記成「訪客」）。平常建議維持 `false`。

> 名單改完最多 2 分鐘生效（程式有 2 分鐘快取）。

### 5. 部署成網頁

1. 右上角「部署」→「新增部署作業」→ 齒輪選 **「網頁應用程式」**。
2. 設定：
   - 執行身分：**我（你的 Gmail）**
   - 誰可以存取：**所有人**
3. 按「部署」，複製出現的網址（長得像 `https://script.google.com/macros/s/AKfycb.../exec`）。
4. 把這個網址填進本專案的 `mock-exam/config.json` 的 `webAppUrl`，Claude 出完題就會直接給你可以點的連結。

**「所有人」不等於誰都看得到題目**：沒有正確代碼的話，網頁不會給出任何題目；正確答案從頭到尾只存在 Drive 和伺服器端，不會送到瀏覽器（改分是在伺服器做的）。網址本身也猜不到。

### 6. 之後改程式碼時

改完 `Code.gs` 或 `index` 要重新部署才會生效：
「部署」→「管理部署作業」→ 鉛筆 →「版本」選 **新版本** → 部署。**網址不會變。**

## 怎麼把考卷給孩子

Claude 出完題會給你這種連結：

```
https://script.google.com/macros/s/AKfycb.../exec?id=20260919-乘法公式&k=yx-2026
```

- `id`：考卷編號
- `k`：作答代碼（先填好，孩子點開就直接進去，不用打字）

不想在連結裡放代碼的話，直接給 `.../exec`，讓他自己輸入代碼，進去會看到所有指派給他的考卷清單。

手機 / iPad 直接用瀏覽器開就可以，**不需要 Claude 帳號，也不需要登入 Google**。作答中途會存在瀏覽器裡，關掉再開不會不見。

## 成績存在哪

`模擬試題/作答紀錄`（Google 試算表），每交一次卷一列：

| 欄位 | 說明 |
|---|---|
| 作答編號 / 時間 | |
| 考卷ID / 科目 / 年級 / 章節 | |
| 學生 / 代碼 | 從名單對出來的 |
| 輪次 | 首次、重做（只重做錯題） |
| 客觀題得分 / 非選自評 / 總分 / 滿分 | 非選是孩子自己對照參考答案打的 |
| 錯題 | 例如「選擇題3、填充題2」 |
| 明細JSON | 每題的作答與正解，給 Claude 做錯題分析用 |

下次在 Claude Code 問「宇翔最近數學錯什麼」，它會直接讀這張表。

## 關於「Google 帳號白名單」

你原本問的是能不能限定「我同意的 Google 帳號」才能做。老實說明目前的狀況：

- 把存取權設成「擁有 Google 帳戶的任何人」的話，孩子/學生會被強迫登入 Google，**但個人 Gmail 帳號寫的 Apps Script 讀不到訪客的 email**（Google 只有在同一個 Workspace 網域內才會給），所以程式沒辦法據此比對白名單。真要做到需要另外去 Google Cloud Console 開 OAuth 用戶端，設定繁瑣又容易壞。
- 所以這版用**代碼白名單**：一人一組代碼，寫在 `名單.json`，伺服器端驗證，隨時可以停用或換掉，效果跟帳號白名單一樣（可控、可撤銷、可分組），而且學生不用登入 Google——對家教學生用共用 iPad 的情況反而更順。
- 如果之後真的要收費、要綁帳號，再跟 Claude 說，可以升級成 Google 登入版。
